# 📘 단어 스캔 학습 (iPad용)

영어 단어책 사진 → 글자 인식 → 단어 지우기 → 빈칸 문제 → 채점 → 오답 복습까지 하는 아이패드 웹앱입니다.
설치 없이 아이패드 Safari에서 열고, **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 실행 방법 (맥 없이)

1. 아이패드 Safari에서 **https://elth100.github.io/word-study/** 를 엽니다.
2. 공유 버튼 › **홈 화면에 추가**를 누르면 앱 아이콘이 생겨요.

> 처음 한 번은 인터넷이 필요해요(글자 인식 데이터 내려받기). 그다음부터는 인터넷이 없어도 앱이 열려요.

### 프로그램을 고친 뒤 다시 올리기
이 폴더에서 `git add -A && git commit -m "수정" && git push` → 1~2분 뒤 같은 주소에 반영돼요.

### (선택) 맥에서 직접 켜기
`start.command`를 Finder에서 더블클릭 → 창에 나오는 주소로 접속 (맥과 아이패드가 같은 와이파이여야 함)

## 사용 순서

| 단계 | 하는 일 |
|---|---|
| 1. 📷 사진으로 스캔 | 카메라로 찍거나 사진을 고름 → 단어가 있는 부분을 드래그해서 선택 → **글자 읽기** |
| 2. ✎ 텍스트 수정 | 잘못 읽힌 글자가 있으면 고침 |
| 3. 🧽 지우기 | 펜슬/손가락으로 단어를 **한 번 탭하면 한 단어**가 지워짐 (다시 탭하면 복구). 펜슬로 쓱 그으면 여러 단어를 한 번에 |
| 4. 📝 문제 만들기 | 지운 자리가 네모 빈칸이 된 문제지 생성 |
| 5. 답 쓰기 | 키보드 입력 또는 애플 펜슬로 칸 위에 바로 쓰기(손글씨 입력) · ✏️ 버튼은 큰 손글씨 패드 |
| 6. ✅ 문제 풀이 (채점) | 원래 단어와 비교해 ○/✕ 표시, 틀린 칸 옆에 정답, 점수 표시 |
| 7. 💾 저장 | 문제·답·채점이 기록에 저장되고, 틀린 문제는 오답노트에 모임 |
| 8. ❌ 틀린 문제 다시 풀기 | 오답노트 문제만 모아서 같은 방식으로 풀고 채점 |

## 추가로 넣은 기능

- **영어 전부 / 한글 전부 지우기** — 한 번에 영어 시험 또는 뜻 시험으로 전환
- **빈칸 묶기** — `give up`처럼 이어서 지운 단어는 한 칸으로 (설정에서 끌 수 있음)
- **너그러운 채점** — 대소문자·띄어쓰기·문장부호 무시, 뜻이 여러 개(`사과/능금`)면 하나만 맞아도 정답
- **정답 인정 버튼** — 손글씨 인식이 틀렸거나 비슷한 뜻을 썼을 때 직접 정답 처리
- **💡 힌트** (첫 글자 보기), **🔀 문제 섞기**, **빈칸 줄만 보기**
- **🔊 발음 듣기** — 문서에서 영어 단어를 탭하거나, 채점 후 🔊 버튼
- **오답노트** — 틀린 횟수 기록, 연속 N번(기본 2번) 맞히면 '외운 단어'로 이동
- **학습 기록** — 지난 시험 다시 보기 / 같은 시험 다시 풀기, 평균 점수 통계
- **📷 페이지 추가** — 여러 장을 한 단어장으로, **🖼 원본** 사진 확인
- **💾 백업/복원** — 파일로 내보내 다른 기기로 옮기기

## 알아둘 점

- **애플 펜슬로 칸에 바로 쓰기**는 iPadOS의 '손글씨 입력(Scribble)' 기능을 씁니다.
  설정 › Apple Pencil › **손글씨 입력**이 켜져 있어야 해요. 한국어 손글씨가 칸에 바로 안 써지면 ✏️ 손글씨 패드를 쓰세요.
- 사진은 **밝은 곳에서 반듯하게**, 단어 부분만 선택하면 인식률이 크게 좋아져요.
- 데이터는 아이패드 안(브라우저 저장소)에만 저장돼요. Safari에서 오래 안 쓰면 지워질 수 있으니 **홈 화면에 추가**해서 쓰고, 가끔 **백업**하세요.

## 파일 구성

- `index.html` — 화면 뼈대
- `style.css` — 디자인 (아이패드 가로/세로, 다크 모드 대응)
- `app.js` — 모든 기능 (OCR, 지우기, 문제, 채점, 저장, 오답노트)
- `start.command` — 맥에서 서버 켜기
